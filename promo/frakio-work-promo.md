# Frakio Work：一个让我不再纠结的 Hermes 多 Agent 工作台

用了大半年各种 Hermes Web UI 和第三方客户端，说实话，没有一个是让我用得舒服的。

不是界面丑得让人不想打开，就是多 Agent 协作形同虚设——所谓的"多 Agent"就是把几个 AI 放在同一个页面里，各聊各的，互不相干。配置还得一个 Agent 来一遍，换模型？再来一遍。

所以我自己做了一个。

## 它是什么

Frakio Work，基于 Hermes Agent 的多 Agent 协作工作台。桌面应用，Electron 打包，macOS 和 Windows 上都能跑。后端是 Hermes Agent 驱动，前端我缝合了几家产品的交互思路——Codex 的动态侧边栏、Arc 的工作区概念、Accio Work 的任务区布局，加上我自己对多 Agent 协作的理解。

说人话就是：**一个把多个 AI 角色放在一起，让它们能随时协同干活的地方。**

至于界面，标准很简单：每天要用的东西，不能丑。

## 为什么不做另一个 Web UI

Hermes Agent 本身是一个优秀的 AI 内核，但它的官方 Web UI 和大部分第三方客户端，在我看来有两个核心问题：

**第一是协作太弱。** 在真实的项目场景里，我需要同时跟好几个 Agent 打交道。一个写文案的、一个做设计的、一个管技术的、一个看市场的。之前的工具里，我只能切来切去，要么就把他们放在同一页各自打字，根本没有"协作"这回事。

**第二是界面审美。** 作为一个每天要用 8-10 小时的工具，如果界面让我不想打开，它功能再多我也用不下去。做 Frakio Work 的时候我给自己定的原则是：做一个我愿意每天打开的工作台。

## 几个比较核心的设计

### @ 召唤 —— 不是切换，是协作

这是整个产品里我最满意的一个交互。

你在对话过程中输入 **@**，可以随时把另一个 Agent 叫进来。不是在两个窗口之间切来切去，是让它们**同时存在于同一段对话里**。

举个例子，我在跟 Kai（营销 Agent）聊一篇博客的选题，聊到一半觉得需要 Nora（电商 Agent）看看这个选题在独立站运营上有没有执行空间——@Nora，她直接进来，看到前面的上下文，接着聊。不需要我重新交代背景。

对话顶部可以切换跟随模式：默认模式下，不 @ 谁就是默认 Agent 回复；对话跟随模式下，你 @ 了谁接下来就由谁接管。两种场景都覆盖了。

### 工作区：一个空间管一件事

Arc 浏览器的用户应该很熟这个概念。

我的使用方式是这样的：一个工作区归跨境电商独立站，一个工作区管博客内容创作，一个工作区做 AI 工作流实验，一个工作区放日常杂谈。

每个工作区可以自定义名字、图标，甚至主题色——支持单色或者最多三色渐变，亮度、噪点都可以调。不同工作区之间的对话完全隔离，不会互相干扰。

我把之前所有零散的对话收进了不同的工作区之后，最大的感受是——**我终于知道上次聊到哪里了。**

### 模型配置：一次配好，全家共享

Hermes Agent 里每个 Agent 的模型配置是独立的。如果你有六七个 Agent，就要配六七次。

Frakio Work 改成了全局模型池——你添加的模型 Provider 和密钥，所有 Agent 都能选。配一次就够了，新 Agent 建好直接选模型，不用再从零配置一遍。

Agent 管理也做成了卡片式，头像、名字、默认模型、默认 Agent，一张卡片看完，不用翻菜单。

### Obsidian 仓库协作（开发中）

这是接下来的重头戏。

多 Agent 要真正协作，不能只靠聊天的上下文窗口。每个 Agent 需要有共同的"工作底稿"——一份本地 Markdown 文件，大家都能读，都能写。

Frakio Work 的开发方向是关联本地 Obsidian 仓库，Agent 根据仓库里的规则索引和项目文件来工作。这个功能还在打磨，但我已经在用原型了：我的创世神 AI 团队整个知识库就在 Obsidian 里，Agent 可以直接访问规则文档、项目阶段文件、复盘记录。不用我把上下文塞进提示词里。

做好了之后，完整的用法我会在博客上写教程。

## 开源 & 下载

Frakio Work 是开源的，MIT 协议。

**macOS 用户**直接下载 DMG 安装包就行。因为还没做 Apple 签名，第一次打开如果提示"已损坏"，跑一行命令：

```bash
xattr -dr com.apple.quarantine "/Applications/Frakio Work.app"
```

**Windows 用户**也不用等了——自 0.1.5 开始已经提供 Windows 桌面安装包，内置 Python、Node.js 和 Hermes Runtime，开箱即用。我手头没有 Windows 机器做深度测试，遇到问题欢迎在 GitHub 反馈。

GitHub Releases 页面：https://github.com/MadsGao/frakio-work/releases

Linux 用户或者想从源码跑也行：

```bash
git clone https://github.com/MadsGao/frakio-work.git
cd frakio-work
npm ci
npm run dev
```

Web UI 默认在 `http://127.0.0.1:5173`，API 在 `http://127.0.0.1:8787`。
