一：主控用户端（Web / 桌面工作台）

1.1 多 Agent 协同会话
1.1.1 团队 Agent 召集与流式对话
功能详细描述：1.在主输入框中输入消息，或通过 @ 符号即时唤起特定 Agent 协同；2.Agent 之间支持自主互相 @ 讨论，自动展示打字机流式回复与工具意图；3.支持多轮会话上下文压缩与消息点赞点踩反馈。

1.1.2 协作决策与审批托盘
功能详细描述：1.当 Agent 执行文件修改或敏感系统命令时，主界面弹出审批托盘；2.用户可一键批准、拒绝或提供额外澄清指示；3.支持多选选项式问答卡片交互。

1.1.3 会话跟随模式与项目沉淀
功能详细描述：1.支持在顶栏切换默认跟随与对话跟随模式；2.支持将当前高价值对话一键沉淀为工作区专属项目。

1.2 团队 Agent 配置中心
1.2.1 Agent 资料与个性化配置
功能详细描述：1.支持创建具备独立角色与人格的 Agent 卡片；2.支持本地上传头像并进行可视化裁剪；3.支持编辑 Agent 的 Soul 定位与常驻系统提示词。

1.2.2 多运行时内核指派
功能详细描述：1.支持为每个 Agent 选择不同的执行内核（Hermes 长期记忆、Pi 编码与工具、Codex、Claude Code）；2.各内核沙箱环境严格隔离，保障数据独立性。

1.3 模型中心与提供商管理
1.3.1 模型渠道配置
功能详细描述：1.统一管理 OpenAI、Anthropic、Kimi、GLM、DeepSeek 等各大模型渠道；2.支持自定义 Base URL、API Key 与可用模型列表；3.支持一键网络可用性连通检测与响应测速。

1.3.2 角色模型自由分派
功能详细描述：1.支持为不同 Agent 分配不同的主模型；2.支持独立指派视觉理解辅助模型与长期记忆提炼模型。

1.4 知识库与本地资料库（Vaults）
1.4.1 本地 Obsidian 资料库连接
功能详细描述：1.支持绑定本地 Markdown 资料库目录；2.自动解析文件树结构并支持在线预览；3.多 Agent 可在会话中实时调用资料库规则索引。

1.5 多工作区与视觉主题
1.5.1 工作区场景划分
功能详细描述：1.支持创建多个业务工作区并设置专属名称与图标；2.支持单色与三色渐变配色及噪点纹理调节。

1.5.2 外观与紧凑模式
功能详细描述：1.支持深色模式、浅色模式与跟随系统外观；2.支持切换紧凑布局与舒适布局。
