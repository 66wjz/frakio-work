## 一、项目概述

Frakio Work 是一个专注于多 Agent 深度自然协作的现代化 AI 工作台。系统深度整合 Hermes、Pi、Codex 与 Claude Code 四大核心运行时，以 Hermes 为生活长期记忆与进化中枢，以 Pi/Codex 为编码与高阶工具执行引擎，实现单会话多 Agent 自主沟通、知识库（Vaults）深度联动与一站式多工作区资产管理。

---

## 二、用户角色定义

| 角色 | 说明 | 主要场景 |
| :--- | :--- | :--- |
| **工作台主控用户 (User)** | 开发者/知识工作者/自媒体运营者 | 建立多工作区、下达复合任务、与多 Agent 协同对话、审阅执行差异并做最终决策。 |
| **执行 Agent (AI Agent)** | 具备特定人格、工具集与运行内核的智能体 | 接收上下文、自主工具调用、多 Agent 间互相 @ 讨论协作、维护长期记忆与知识进化。 |
| **外部通道用户 (Channel User)** | 飞书/企业微信等企业 IM 终端用户 | 在外部即时通讯群聊中通过 `@Bot` 触发工作台调度并接收执行结果。 |

## 三、用户端需求（Web / 桌面客户端）

**核心目标：** 提供流畅、极简、无缝多 Agent 协作的工作台交互体验。

### 1. 多 Agent 协同与会话管理
- **用户故事**：作为主控用户，我想要在一个对话流中随时召集多个具备不同专长的 Agent，以便它们能像真实团队一样共同解决复杂任务。
- **详细描述**：
  - 支持自然语言 `@Agent` 实时召集与切换。
  - 支持对话跟随模式（默认跟随 / 对话跟随 / 转为项目）。
  - 支持 Agent 之间最多 64 轮自主互相 `@` 与深度推演。
  - 支持打字机渐显、流式推流、富工具执行意图展示。
  - 支持敏感命令/文件变更的确认审批（Approval）与多选澄清（Clarification）托盘。

### 2. 团队 Agent 与多内核配置中心
- **用户故事**：作为主控用户，我想要为每个 Agent 自由配置底层 Harness 运行时、提示词 Soul、专属模型与长期记忆，以便打造专职团队。
- **详细描述**：
  - 集中卡片化管理 Agent 列表、头像裁剪上传与基础资料。
  - 支持为不同 Agent 独立指派内核（Hermes 长期记忆 / Pi 编码与工具调度 / Codex / Claude Code）。
  - 每个 Agent 拥有独立的 Profile、配置与沙箱隔离环境，互不干扰。

### 3. 模型中心与统一 Provider 调度
- **用户故事**：作为主控用户，我想要一次性配置多个模型提供商（OpenAI、Anthropic、Kimi、GLM、DeepSeek 等），并在多个 Agent 间自由复用。
- **详细描述**：
  - 支持统一配置 API Key、Base URL、自定义模型清单与定价计费。
  - 支持模型连接可用性探测与延迟测速。
  - 支持主模型、视觉辅助模型、记忆审阅模型的独立指派。

### 4. 知识库与本地 LLM Wiki 资料库（Vaults）
- **用户故事**：作为主控用户，我想要连接本地 Obsidian/Markdown 资料库，以便 Agent 协作时可直接检索本地知识并保持上下文同步。
- **详细描述**：
  - 支持关联本地 Vault 目录并建立文件树索引。
  - 支持全文检索、关联规则提取与多 Agent 共享知识读写。

### 5. 多工作区与视觉定制
- **用户故事**：作为主控用户，我想要按项目或业务场景划分多个独立工作区，并自定义视觉主题。
- **详细描述**：
  - 支持创建多个独立工作区（开发、日常、自媒体等）。
  - 支持单色与三色渐变配色、噪点控制与深浅色模式跟随系统。

## 四、非功能性需求

### 4.1 性能与响应
- 前端页面首屏加载时间 < 800ms；
- 本地 API 响应延迟 < 50ms（非模型推理流）；
- SSE 流式打字机渲染平滑，无卡顿掉帧。

### 4.2 兼容性与运行环境
- 支持 macOS (Apple Silicon / Intel)、Windows 10/11 x64、Linux x64；
- 前端支持 Chrome 110+、Edge、Safari、Firefox 主流现代浏览器。

### 4.3 安全与沙箱隔离
- 敏感 API Key 与密钥保存在 `data/workbench-state.json` 或系统凭据中，绝不纳入 Git 仓库；
- 多内核运行环境隔离，每个 Agent 独享沙箱路径，禁止越权污染系统全局 CLI 配置。
