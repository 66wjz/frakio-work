## 1. 认证与系统控制接口 (`auth-and-system`)

### 1.1 获取系统登录状态
- **URL**：`GET /api/auth/status`
- **说明**：检查是否启用 Web 密码管控及当前认证态。
- **出参**：
  ```json
  {
    "managed": true,
    "authenticated": true,
    "passwordChangeRequired": false,
    "defaultPasswordHint": ""
  }
  ```

### 1.2 管理员登录
- **URL**：`POST /api/auth/login`
- **入参**：`{ "password": "..." }`
- **出参**：`{ "ok": true, "passwordChangeRequired": false }`

---

## 2. 团队 Agent 接口 (`agents`)

### 2.1 获取全量 Agent
- **URL**：`GET /api/agents`
- **说明**：获取工作区当前配置的所有 Agent 列表。

### 2.2 保存 Agent
- **URL**：`POST /api/agents`
- **入参**：包含 `id`, `name`, `role`, `runtimeId`, `modelValue`, `soul`, `avatarUrl`。

---

## 3. 会话与运行流接口 (`threads-and-chat`)

### 3.1 创建会话运行
- **URL**：`POST /api/threads/:threadId/runs`
- **出参**：`202 Accepted`，包含 `runId`。

### 3.2 SSE 事件推流
- **URL**：`GET /api/threads/:threadId/runs/:runId/stream`
- **说明**：建立流式打字机与工具调用推流。

---

## 4. 模型中心接口 (`models-and-providers`)

### 4.1 模型列表与提供商
- **URL**：`GET /api/models`

### 4.2 模型连通性测速
- **URL**：`POST /api/models/test`
- **入参**：`{ "provider": "kimi-coding", "baseUrl": "...", "apiKey": "...", "model": "..." }`
