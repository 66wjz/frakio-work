## 一、环境依赖矩阵

| 依赖项 | 最低版本要求 | 推荐版本 | 说明 |
| :--- | :--- | :--- | :--- |
| **Node.js** | >= 20.x | Node 24.x | 主 API 与前端构建运行环境 |
| **Python** | >= 3.10 | Python 3.11/3.12 | Hermes / Pi Bridge 运行时环境 |
| **uv** | 最新版 | 最新版 | 极速 Python 包与虚拟环境管理器 |
| **Git** | >= 2.30 | 最新版 | 版本控制与上游同步 |

---

## 二、源码开发模式启动

```bash
# 1. 克隆代码 (建议使用您的个人 Fork 仓库)
git clone https://github.com/66wjz/frakio-work.git
cd frakio-work

# 2. 安装 Node 依赖
npm install

# 3. 构建 Python Bridge 运行时
npm run runtime:build

# 4. 启动前后端联合热开发服务器
npm run dev
```

- **前端 Web 界面**：`http://127.0.0.1:5173`
- **后端 API 服务**：`http://127.0.0.1:8787`

---

## 三、Docker 容器化部署

```bash
docker run -d --name frakio-work \
  -p 8787:8787 \
  -v frakio-work-data:/data \
  -v "$PWD:/workspace" \
  ghcr.io/madsgao/frakio-work:latest
```

---

## 四、数据与安全隔离

所有工作台状态、密钥与日志统一保存在 `~/.frakio-work` 与 `~/.hermes/profiles/`，严禁将包含 API Key 的 `data/` 目录上传至公网。
